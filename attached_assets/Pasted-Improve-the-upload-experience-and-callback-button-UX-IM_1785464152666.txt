PART 2 — Professional Callback UX
━━━━━━━━━━━━━━━━━━━━━━

Current problem:

After pressing any inline button,

the bot takes 3–7 seconds.

Users think the bot is frozen.

Fix this.

━━━━━━━━━━━━━━━━━━━━━━

For EVERY callback button:

Immediately execute

answerCallbackQuery()

before ANY Firestore query,

before Excel parsing,

before heavy processing,

before conversation navigation.

Purpose:

• Remove Telegram loading spinner instantly.
• Confirm button click immediately.
• Make bot feel responsive.

━━━━━━━━━━━━━━━━━━━━━━

If processing takes more than about 1 second,

show a temporary status message BELOW the user's message.

Example

━━━━━━━━━━━━━━━━━━━━━
⏳ Loading...
━━━━━━━━━━━━━━━━━━━━━

Please wait...

Processing your request...

━━━━━━━━━━━━━━━━━━━━━━

When processing finishes,

replace ONLY the loading/status message with:

• Next screen
OR
• Success report
OR
• Upload report
OR
• Error report

Never leave loading message on screen.

━━━━━━━━━━━━━━━━━━━━━━

If processing fails,

show

━━━━━━━━━━━━━━━━━━━━━
❌ Operation Failed
━━━━━━━━━━━━━━━━━━━━━

Reason:

<simple readable reason>

Please try again.

Never expose raw Firestore or internal errors.

━━━━━━━━━━━━━━━━━━━━━━

The bot must always respond instantly to button clicks.

Users should never feel the bot is frozen.
