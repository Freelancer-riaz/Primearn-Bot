PART 2 — Button Loading Experience
━━━━━━━━━━━━━━━━━━━━━━

Current problem:

When user presses any inline button,

Bot sometimes needs 3–7 seconds.

During this time nothing happens.

Users think the bot is frozen.

Improve this.

━━━━━━━━━━━━━━━━━━━━━━

Immediately after pressing ANY callback button:

• Category
• Submission Type
• Back
• Upload
• Report
• Admin buttons

Answer the callback immediately.

Use:

answerCallbackQuery()

so Telegram instantly removes the loading spinner.

If the next screen takes more than 1 second,

show a temporary loading message.

Example:

━━━━━━━━━━━━━━━━━━━━━
⏳ Loading...
━━━━━━━━━━━━━━━━━━━━━

Please wait...

or

Processing your request...

Then automatically replace that loading message with the actual next page.

Never leave the loading message on screen.

━━━━━━━━━━━━━━━━━━━━━━

If any exception happens,

show a friendly message.

Example:

━━━━━━━━━━━━━━━━━━━━━
❌ Operation Failed
━━━━━━━━━━━━━━━━━━━━━

Reason:

<simple explanation>

Please try again.

━━━━━━━━━━━━━━━━━━━━━━

Never leave user waiting with no response.

Every button press must immediately give visual feedback.
